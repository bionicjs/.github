# bionicjs

**TypeScript runs the web. Python runs the intelligence.**

bionicjs is a full-stack framework for building intelligent web apps: React, Vite and Nitro on the web side, Python for AI and background jobs, wired together by one config with typed contracts between them.

    `npx create-bionicjs-app@latest`

- `bionicjs`: the framework
- `@bionicjs/*`: plugins for auth, database, AI providers and jobs

MIT licensed. Early stage; APIs may change before 1.0.
